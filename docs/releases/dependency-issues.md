# Dependency issues

## OpenAPI generator development dependency

A 2026-11-03 audit reported GHSA-g3hv-75wg-m249 through `openapi-typescript@7.13.0` → `@redocly/openapi-core@1.34.23` → `minimatch@5.1.9`. An override to `@redocly/openapi-core@2.73.0` made that audit clean but broke schema generation with `ERR_PACKAGE_PATH_NOT_EXPORTED` for `./lib/ref-utils.js`, so it was reverted.

Re-audit on 2026-11-07: `npm audit --json` reports zero vulnerabilities for the current `package-lock.json`; the same package versions remain locked. The previous advisory no longer appears in the current scanner result. Do not reinstate the incompatible override. Evidence is `.acceptance/dependency-inventory-971fa5b/npm-audit.json`. Re-run `npm audit` after dependency changes.

Re-audit on 2026-11-25: `npm audit --json` reports zero findings for the current npm lockfile. `uv audit --locked --output-format json` initially found CVE-2025-71176 in development-only `pytest 8.4.2`; it emitted the same advisory twice under its GHSA and PYSEC aliases. The advisory describes predictable pytest temporary-directory handling on Unix. Upstream fixes it in pytest 9.0.3 ([release notes](https://github.com/pytest-dev/pytest/releases/tag/9.0.3); [advisory](https://github.com/advisories/GHSA-6w46-j5rx-g56g)). `pytest-asyncio 1.4.1.post1` supports pytest 9 ([release history](https://github.com/pytest-dev/pytest-asyncio/releases)). X.A.A. now requires pytest `>=9.0.3,<10` and locks 9.2.0; a second locked Python audit reports zero findings across 79 packages. Before/after reports and the npm report are retained in `.acceptance/dependency-security-20261125/`. The Windows source suite passes locally with pytest 9.2.0 (1,767 passed, 8 skipped); Ruff, format, Pyright, lock consistency and release-notice reference checks pass. `cargo audit` was unavailable in the initial pass; the subsequent Cargo audit and fixes are recorded below. Exact-source Windows source and installer workflows passed on `91796731` ([source 45580841474](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/45580841474), [installer 45580862192](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/45580862192)).
