# Unsigned Windows installer development build

`npm ci`, `uv sync --locked` and `npm run build:installer` build the frontend, freeze the Python engine, compile the release Tauri executable with Cargo.lock enforced and produce an NSIS x64 setup executable. The pinned npm CLI is @tauri-apps/cli 2.12.4. The separate tauri.release.conf.json overlay enables current-user installation; the base development bundle stays disabled. LM Studio remains a separate prerequisite. Missing WebView2 uses Tauri's download-bootstrapper option, so that dependency setup may require network access. See the official Tauri Windows installer guide: https://v2.tauri.app/distribute/windows-installer/.

Outputs are staged in `build/installer` with sizes and SHA-256 values, alongside a `build/native-release` directory for restricted-PATH smoke checks. The installer is deliberately unsigned and is a development artifact, not a completed production release. The 2026-11-07 `npm audit` result is clean; see [dependency issues](dependency-issues.md). Signing, a complete license decision, package attribution and copyright review, a durable published upgrade baseline and clean end-user-machine coverage remain unfinished. A provisional notice draft exists at [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md); the release overlay bundles it with the dependency inventory and release notes, and the installed-package smoke verifies each file against its manifest SHA-256. The installed desktop WebView acceptance also runs a deterministic local provider flow and now records/clears a Chromium fake-device voice clip, checking microphone track teardown without transcription or live inference; the local native-development smoke passed, and hosted installer run [42655212402](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/42655212402) verified the feature inside the installed package with no transcription or live inference.

Local release boot `.acceptance/5238a416-a464-4f85-8298-3360c7f6e1b3/` passed with PATH limited to Windows System32 and Python/virtualenv paths removed. The real release desktop starts its adjacent frozen engine, authenticates API requests, creates no runs, requests no inference and closes with a graceful engine shutdown. This proves standalone release startup on the development machine; it does not prove installation/uninstallation or clean-machine prerequisites. The first completed local installer is approximately 22.13 MiB. The current manifest is regenerated for each build; hashes are artifact-specific rather than a reproducible-byte guarantee.

The Windows installer CI job runs after source checks on main, installs the pinned Rust toolchain, builds the package and uploads an unsigned installer/manifest artifact for 14 days. `scripts/installer_ci_smoke.ps1` is restricted to a disposable GitHub Actions runner, refuses an existing test destination, installs under RUNNER_TEMP, checks both binaries, runs the installed app under restricted PATH, then uninstalls and checks that binaries were removed and a default-data-directory marker was preserved. ## Version-to-version upgrade acceptance

The application version is advanced consistently across Python, npm, Cargo and Tauri from 0.1.0 to 0.1.1. The hosted installer job downloads the checksum-verified 0.1.0 artifact from run 42181905058 (artifact retention: 14 days), installs it into a fresh RUNNER_TEMP directory, then runs the current 0.1.1 setup over the same directory. Before upgrading, the fixture helper creates a durable run, ordered events and a binary artifact, then removes schema-19-through-22 additions and sets SQLite `user_version=18`. The upgraded installed engine opens and migrates this schema-18 profile, backs it up and restores it; an independent verifier compares the recovered values and bytes to the pre-upgrade fixture and checks the current schema version, integrity and foreign keys. Hosted run [42668125217](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/42668125217) passed install/upgrade/backup/restore/uninstall using the corrected helper, though its artifact omitted the explicit seeded schema field. Local fixture evidence is `.acceptance/schema18-upgrade-fixture-20261109/verify.json`. This is a short-term CI baseline using a retained 14-day predecessor artifact; durable release upgrade coverage still requires publishing versioned installers. Synthetic data does not establish recovery of an actual user's profile or disaster recovery.
