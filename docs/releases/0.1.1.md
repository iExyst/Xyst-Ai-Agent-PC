# Xyst AI Agent 0.1.1

**Status:** unsigned Windows development build, dated 2026-11-07. This is not a general release; X.A.A. remains under active development and the full release objective is incomplete.

## What is included

- A Windows desktop application with a bundled Python engine. Python and Node.js are not runtime prerequisites. LM Studio is installed separately; users choose a discovered model explicitly.
- Durable runs, saved events, workspace read/edit tools, candidate review, backup and restore, and local CLI access through the same coordinator.
- Bounded specialist assignments using isolated workspace snapshots, scoped permissions, saved evidence, review, and explicit integration controls.
- Optional browser, MCP, schedules, and channel integrations with per-tool or per-destination controls. Their coverage is partial and some paths require separately configured services or credentials.
- The source is licensed under MIT in the root LICENSE. The pinned Hermes capability matrix, dependency inventory and provisional third-party notice text are included in the source tree and staged with the installer.

## Installation

Use the unsigned per-user Windows installer from the linked GitHub Actions artifact. The installer is intended for evaluation on Windows. Connect to a separately installed LM Studio instance, select a model, and choose a workspace. See the [user guide](../user-guide.md), [Windows installer evidence](windows-installer.md), and [local model baseline](../evaluations/local-model-baseline.md).

This build has passed automated Windows source checks and disposable installer acceptance for upgrade, application startup, backup/restore, uninstall, and preservation of the test user's data. Those tests do not establish clean-machine deployment readiness or recovery of real user data.

## Known limitations

- The installer is unsigned, and normal-user clean-machine acceptance, durable published upgrade baselines, and release/legal review are incomplete.
- The application source license is MIT. The bundled third-party notice text remains provisional; package attribution, copyright review, and platform-conditional dependency coverage remain open.
- X.A.A. does not claim full Hermes parity. The matrix records partial implementations and unverified integrations.
- Live acceptance for external messaging, broad model reliability, all specialist recovery/conflict cases, and several provider/backend integrations remains incomplete. Missing credentials or services must be configured separately.
- Windows is the first target. Linux and mobile releases are not included.

See [`progress.md`](../progress.md) for dated implementation evidence and open acceptance gates.
