# Xyst AI Agent 0.1.1

**Status:** unsigned Windows development build, updated 2026-11-14. This is not a general release; X.A.A. remains under active development and the full release objective is incomplete.

## What is included

- A Windows desktop application with a bundled Python engine. Python and Node.js are not runtime prerequisites. LM Studio is installed separately; users choose a discovered model explicitly.
- Durable runs, saved events, workspace read/edit tools, candidate review, backup and restore, and local CLI access through the same coordinator.
- Settings exports verified portable backups and restores them into a separate profile. Switching profiles requires explicit owner confirmation and restarts the desktop; the previous profile remains available.
- Bounded specialist assignments using isolated workspace snapshots, scoped permissions, saved evidence, review, and explicit integration controls.
- Optional browser, MCP, schedules, and channel integrations with per-tool or per-destination controls. Their coverage is partial and some paths require separately configured services or credentials.
- The source is licensed under MIT in the root LICENSE. The pinned Hermes capability matrix, dependency inventory and provisional third-party notice text are included in the source tree and staged with the installer.

## Installation

Download the unsigned per-user Windows installer from the `xaa-windows-installer-unsigned` artifact on [hosted installer run 43605529851](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/43605529851). On its **Summary** page, extract the artifact ZIP and run `Xyst AI Agent_0.1.1_x64-setup.exe`. The installer is intended for evaluation on Windows. Connect to a separately installed LM Studio instance, select a model, and choose a workspace. See the [user guide](../user-guide.md), [Windows installer evidence](windows-installer.md), and [local model baseline](../evaluations/local-model-baseline.md).

The current 0.1.1 installer passed disposable hosted Windows acceptance for AppContainer execution, startup, upgrade from 0.1.0, recovery, standard-user installation, uninstall, and data handling (run [43605529851](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/43605529851)). Its first attempt hit an intermittent AppContainer temp-directory permission error; the rerun on a clean runner passed. The manual workflow skipped the source job; source run [43603741402](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/runs/43603741402) passed. This does not establish broad clean-machine deployment or recovery of real user data.

## Known limitations

- The installer is unsigned. Hosted per-user and standard-account acceptance and a published 0.1.0 upgrade baseline now exist. An intermittent AppContainer temp permission failure remains unresolved; broad independent-machine compatibility and release/legal review remain incomplete.
- The application source license is MIT. The bundled third-party notice text remains provisional; package attribution, copyright review, and platform-conditional dependency coverage remain open.
- X.A.A. does not claim full Hermes parity. The matrix records partial implementations and unverified integrations.
- Live acceptance for external messaging, broad model reliability, all specialist recovery/conflict cases, and several provider/backend integrations remains incomplete. Missing credentials or services must be configured separately.
- Windows is the first target. Linux and mobile releases are not included.

See [`progress.md`](../progress.md) for dated implementation evidence and open acceptance gates.
