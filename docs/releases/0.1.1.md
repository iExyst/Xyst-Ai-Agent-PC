# Xyst AI Agent 0.1.1

**Status:** unsigned Windows development build, updated 2026-11-28. This is not a general release; X.A.A. remains under active development and the full release objective is incomplete.

## What is included

- A Windows desktop application with a bundled Python engine. Python and Node.js are not runtime prerequisites. LM Studio is installed separately; users choose a discovered model explicitly.
- Durable runs, saved events, workspace read/edit tools, candidate review, backup and restore, and local CLI access through the same coordinator.
- Settings exports verified portable backups and restores them into a separate profile. Switching profiles requires explicit owner confirmation and restarts the desktop; the previous profile remains available.
- Bounded specialist assignments using isolated workspace snapshots, scoped permissions, saved evidence, review, and explicit integration controls.
- A System Monitor with host resource readings and detected GPU memory telemetry. NVIDIA utilization uses `nvidia-smi`; Windows GPU-engine counters report the busiest engine for other adapters when available. Provider setup can request an estimate-only LM Studio load check without loading the model; chat refreshes an existing stale model catalog before honoring an explicit LM Studio resource warning. These readings are advisory and do not reserve hardware or guarantee that a model will load.
- Optional browser, MCP, schedules, and channel integrations with per-tool or per-destination controls. Their coverage is partial and some paths require separately configured services or credentials.
- The Email channel reduces HTML-only message bodies to bounded visible plain text without rendering markup or fetching remote content. After sender allowlisting and trusted aligned DMARC checks, it accepts one supported PDF, DOCX, XLSX, UTF-8 TXT, Markdown, or CSV attachment up to 4 MiB. Source and extracted text are retained as untrusted artifacts. Live mailbox acceptance remains open.
- Paired private Telegram users can send one supported PDF, DOCX, XLSX, UTF-8 TXT, Markdown, or CSV document up to 4 MiB, a PCM WAV document up to 4 MiB, or an Ogg/Opus voice note up to 4 MiB and 60 seconds. On Windows, audio is transcribed with the installed offline speech recognizer; original audio and untrusted transcript are retained. Pairing and duplicate-update checks run before download. Live bot interoperability remains open.
- Authenticated A2A tasks can receive one bounded WAV attachment on Windows. X.A.A. transcribes it with the installed offline Windows speech recognizer, stores the original audio, and treats the transcript as untrusted input. Synthetic speech passes through the installed engine. The current physical microphone checks found a device but received zero input (see [native acceptance](native-acceptance.md)); human speech accuracy and microphone-to-ASR remain unverified.
- The source is licensed under MIT in the root LICENSE. The pinned Hermes capability matrix, dependency inventory and provisional third-party notice text are included in the source tree and staged with the installer.

## Installation

Download the latest successful manual package run from the [Engine checks workflow](https://github.com/iExyst/Xyst-Ai-Agent-PC/actions/workflows/engine.yml). Open its `windows-installer` job and download the `xaa-windows-installer-unsigned` artifact. Extract the ZIP, check the included manifest, and run `Xyst AI Agent_0.1.1_x64-setup.exe`. The [Windows installer evidence page](windows-installer.md) records the latest verified artifact, digest, and acceptance scope. The installer acceptance exercises install, upgrade, recovery, standard-user installation, boot and uninstall. This unsigned development build is intended for evaluation on Windows. Connect to a separately installed LM Studio instance, select a model, and choose a workspace. See the [user guide](../user-guide.md) and [local model baseline](../evaluations/local-model-baseline.md).

## Known limitations

- The installer is unsigned. Hosted per-user and standard-account acceptance and a published 0.1.0 upgrade baseline now exist. The AppContainer shim temp permission fix passed three local installed-package cycles and hosted package acceptance; broader independent-machine compatibility and release/legal review remain incomplete.
- The application source license is MIT. The bundled third-party notice text remains provisional; package attribution, copyright review, and platform-conditional dependency coverage remain open.
- X.A.A. does not claim full Hermes parity. The matrix records partial implementations and unverified integrations.
- Live acceptance for external messaging, broad model reliability, all specialist recovery/conflict cases, and several provider/backend integrations remains incomplete. Missing credentials or services must be configured separately.
- Windows is the first target. Linux and mobile releases are not included.

See [`progress.md`](../progress.md) for dated implementation evidence and open acceptance gates.
