## Workspace read preflight retry follow-up

The workspace file/list/search slice retries recognized transient `Path.resolve` and target metadata failures before persisting a tool intent. Only retryable OS error codes receive two bounded retries; access denial, missing paths and containment escapes remain immediate failures. The helper journals a bounded `tool.read_retry` event and the eventual read/list/search still owns its ordinary durable intent/result lifecycle. Evidence and exact remaining scope are recorded in [`../architecture/filesystem-workers.md`](../architecture/filesystem-workers.md) and [`../progress.md`](../progress.md). This is a resilience improvement to the implemented workspace tools, not a claim of broad filesystem or Hermes parity.

Pinned README advertises six messaging gateway families in its quick reference (Telegram, Discord, Slack, WhatsApp, Signal, Email), and its documentation table additionally names Home Assistant.
